## Cómo ejecutarlo
1. Abrir el simulador con `INICIAR_SIMULADOR.bat` y elegir `2` (Go2).
2. En otra terminal, desde `TP02_Programacion_I`: `python mi_desarrollo/mi_tp02.py`
